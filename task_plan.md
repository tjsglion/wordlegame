# Wordle H5 experience upgrade

## Goal
Transform the existing Wordle into a touch-first, scene-led casual H5 daily word adventure without changing game rules or persistence behavior.

## Phases
- [x] Audit current implementation and research contemporary reference patterns.
- [x] Build the Wordle-specific H5 stage, status feedback, and visual hierarchy.
- [x] Verify interaction, mobile layout constraints, type safety, and linting.
- [x] Summarize changes and the remaining product opportunities.
- [x] Generate and analyze an image-led mobile H5 design reference.
- [ ] Implement the scene, game HUD, progression cue, and action dock as a coherent Wordle Quest experience.
- [ ] Verify the redesigned play, completion, and mobile layout states.

## Constraints
- Preserve the user's in-progress Stackdown changes and other unrelated dirty files.
- Keep Wordle state, server validation, sharing, stats, and accessibility behavior intact.
